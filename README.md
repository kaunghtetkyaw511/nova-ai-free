# Thazin Mg Mg Htwe - Portfolio

A responsive navy and gold portfolio website for Thazin Mg Mg Htwe, Graphic Designer.

## Run locally

```sh
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Included

- Premium dark navy and gold visual direction with light and dark modes
- Cover photo hero section
- Work experience, education, certificates, languages, skills, software, and design techniques
- Categorized design showcase generated from the Data 1 design archive
- Clickable phone, email, and Line contact links
- Downloadable CV PDF with download feedback
- Responsive layout for mobile, tablet, and desktop
